# Profile README Benchmark and Design Decisions

**Purpose:** This is a transparent benchmark for the GitHub profile README at [mbilal-OU](https://github.com/mbilal-OU). It does not claim an objective global ranking. The ten examples below were selected as high-visibility public profile repositories with strong reuse, clear identity, or useful interaction patterns.

**Snapshot date:** 31 August 2026. Star and fork counts are live GitHub repository metadata at the time of review.

## What was adopted

1. **One visual hero, not a gallery.** The profile uses the repository-hosted `doc/banner3.jpg` as a clickable hero that opens the research portfolio.
2. **Immediate identity.** Name, doctoral-researcher role, affiliation, and research themes remain visible without scrolling.
3. **Clear destinations.** Portfolio, LinkedIn, Google Scholar, email, and GitHub remain clickable at the top.
4. **Selective featured work.** *Awesome Microbial Pangenomics* is promoted as a text feature and linked from the software ecosystem.
5. **Evidence over decoration.** Publications, research highlights, award information, reproducible software, and an actual contribution calendar remain central.

## What was deliberately not adopted

- Typing animations, visitor counters, contribution snakes, and “trophy” widgets.
- Large walls of technology logos.
- Automatic language or commit statistics that can distract from scientific expertise.
- External assets that are likely to disappear or load unreliably.

These elements are common in developer profiles, but they would make an academic research profile look less focused. The goal here is not to copy popular templates. It is to make a recruiter, collaborator, or scientist understand Muhammad Bilal’s research identity, evidence, and software contributions quickly.
